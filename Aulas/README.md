# 📖 Objetivo da Disciplina

A disciplina tem como objetivo desenvolver aplicações Web modernas e responsivas utilizando Frameworks Front-end, preparando os alunos para criar interfaces organizadas, reutilizáveis e alinhadas às necessidades do mercado de desenvolvimento Web. :contentReference[oaicite:0]{index=0}

Ao final da disciplina o aluno deverá ser capaz de:

- Desenvolver interfaces modernas;
- Criar aplicações utilizando Frameworks Front-end;
- Utilizar Git e GitHub para versionamento;
- Publicar aplicações na Web (Deploy). :contentReference[oaicite:1]{index=1}

# 🌐 O que é Front-end?

O Front-end representa toda a parte visual de uma aplicação, ou seja, aquilo com que o usuário interage diretamente.

É responsável por:

- Interface gráfica;
- Organização dos elementos;
- Experiência do usuário (UX);
- Comunicação com sistemas responsáveis pelo processamento dos dados. :contentReference[oaicite:3]{index=3}

---

# 🚀 Importância dos Frameworks Front-end

Atualmente, grande parte das aplicações Web modernas utiliza Frameworks Front-end, pois eles oferecem:

- Maior produtividade;
- Organização do projeto;
- Reutilização de componentes;
- Facilidade de manutenção;
- Melhor escalabilidade;
- Desenvolvimento mais rápido.

Os principais frameworks apresentados foram:

- React
- Angular
- Vue.js :contentReference[oaicite:4]{index=4} :contentReference[oaicite:5]{index=5}

A primeira atividade proposta consiste em:
