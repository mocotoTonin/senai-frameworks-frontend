## O que são Frameworks Front-end?

Frameworks Front-end são conjuntos de ferramentas, bibliotecas e convenções que padronizam o desenvolvimento de interfaces Web. Eles fornecem uma estrutura pré-definida que facilita e acelera a criação de aplicações.

Entre suas características estão a componentização, programação reativa, ferramentas de build, sistemas de rotas, integração com APIs, suporte a testes e boas práticas de desenvolvimento.

## Framework x Biblioteca

### Framework

Um framework possui uma estrutura definida e controla parte do fluxo da aplicação.

Exemplos:

- Angular;
- Vue.

### Biblioteca

Uma biblioteca oferece recursos que podem ser utilizados conforme a necessidade do desenvolvedor, proporcionando maior flexibilidade.

Exemplos:

- React;
- jQuery.

O React, especificamente, é uma biblioteca JavaScript para construção de interfaces, embora seja frequentemente chamado de framework.

## Tecnologias Estudadas

### React

React é uma biblioteca JavaScript desenvolvida pelo Facebook para criação de interfaces de usuário. Seu desenvolvimento é baseado em componentes reutilizáveis e utiliza conceitos como JSX, Hooks e Virtual DOM.

Principais conceitos estudados:

- Componentes;
- JSX;
- `useState`;
- `useEffect`;
- Gerenciamento de estado;
- Virtual DOM.

### Angular

Angular é um framework completo desenvolvido pelo Google. Ele utiliza TypeScript e oferece recursos como roteamento, HTTP Client, injeção de dependências e ferramentas de geração de componentes.

Principais conceitos estudados:

- Componentes;
- Serviços;
- Data Binding;
- Injeção de Dependência;
- Roteamento;
- Angular CLI;
- TypeScript.

### Vue

Vue é um framework progressivo que permite sua adoção de forma gradual. Possui um sistema de reatividade, componentes e Single-File Components (SFC).

Principais características:

- Programação reativa;
- Componentes;
- Single-File Components;
- Virtual DOM;
- Curva de aprendizado acessível.

### Next.js

Next.js é um framework baseado em React utilizado para desenvolvimento de aplicações Web modernas e full-stack.

Entre seus recursos estão:

- Roteamento baseado em arquivos;
- Server Components;
- Renderização no servidor;
- Otimização de imagens e fontes;
- Layouts;
- APIs;
- Otimizações de desempenho e SEO.

Durante o desenvolvimento, os projetos foram versionados utilizando Git e publicados individualmente no GitHub.

Cada tecnologia possui seu próprio repositório, permitindo organizar os códigos e acompanhar a evolução de cada projeto por meio dos commits.

## Deploy

Após a publicação dos projetos no GitHub, as aplicações foram disponibilizadas online utilizando a Vercel.

Cada projeto possui seu próprio deploy e URL pública.

## Comparação entre as Tecnologias

| Tecnologia | Tipo | Linguagem principal | Característica |
|---|---|---|---|
| React | Biblioteca | JavaScript | Componentização e interfaces |
| Vue | Framework | JavaScript | Reatividade e simplicidade |
| Angular | Framework | TypeScript | Estrutura completa |
| Next.js | Framework React | JavaScript | Recursos para aplicações Web modernas |

Durante a atividade, foi possível observar que cada tecnologia possui uma estrutura e uma forma diferente de organizar e desenvolver aplicações, apesar de todas permitirem a criação de interfaces Web modernas.

## Estrutura dos Projetos

Os projetos foram organizados de forma independente, cada um utilizando a estrutura padrão de sua respectiva tecnologia.

O objetivo foi manter a mesma proposta visual e funcional entre os projetos, permitindo comparar como cada tecnologia implementa componentes, estilos e organização da aplicação.
