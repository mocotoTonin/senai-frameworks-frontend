# CSS — Cascading Style Sheets

O CSS é uma linguagem utilizada para definir a aparência e a apresentação de páginas Web.

Por meio dele, é possível controlar cores, fontes, espaçamentos, tamanhos, alinhamentos e a organização dos elementos HTML.

O CSS permite separar a estrutura da página, desenvolvida com HTML, de sua apresentação visual.

## Box Model

O Box Model é um modelo utilizado pelo CSS para representar como os elementos HTML ocupam espaço na página.

Ele é composto por quatro partes:

| Propriedade | Descrição                                       |
| ----------- | ----------------------------------------------- |
| Content     | Conteúdo do elemento.                           |
| Padding     | Espaçamento interno entre o conteúdo e a borda. |
| Border      | Borda que envolve o elemento.                   |
| Margin      | Espaçamento externo entre os elementos.         |

Esse modelo permite controlar o tamanho dos elementos e os espaçamentos utilizados na organização do layout.

## Flexbox

O Flexbox é um modelo de layout do CSS utilizado para organizar e alinhar elementos dentro de um contêiner.

Entre suas principais funcionalidades estão:

* Alinhamento horizontal e vertical;
* Distribuição de espaço entre elementos;
* Organização em linhas ou colunas;
* Controle do espaçamento entre componentes;
* Criação de layouts responsivos.

O Flexbox facilita a construção de interfaces organizadas e adaptáveis a diferentes tamanhos de tela.

# Atividade 02 — Tailwind CSS

## Tailwind CSS

O Tailwind CSS é um framework CSS que utiliza classes utilitárias para estilizar elementos HTML.

Em vez de criar diversas regras CSS personalizadas, é possível aplicar classes diretamente nos elementos para definir cores, espaçamentos, alinhamentos, tamanhos e outros estilos.

Entre suas características estão:

* Estilização utilizando classes utilitárias;
* Organização dos elementos da interface;
* Controle de cores, tamanhos e espaçamentos;
* Desenvolvimento de layouts responsivos;
* Facilidade na criação e manutenção de interfaces.

## Funcionalidades e conceitos aplicados

* Estruturação da interface com HTML;
* Utilização do Tailwind CSS;
* Aplicação de classes utilitárias;
* Estilização de componentes;
* Organização e alinhamento de elementos;
* Aplicação de tema escuro e detalhes em azul;
* Desenvolvimento responsivo.
