# Aula 01 — Apresentação da Disciplina e Contextualização

## Introdução

A Aula 01 marcou o início da disciplina de **Frameworks Front-end**. Durante a aula foram apresentados os objetivos da disciplina, a metodologia de ensino, os critérios de avaliação e os principais conteúdos que serão trabalhados ao longo do semestre.

Também foram introduzidos conceitos fundamentais sobre desenvolvimento Front-end, versionamento de código, Git, GitHub, frameworks e deploy de aplicações Web.

---

## Objetivos da Disciplina

Ao longo do semestre, o objetivo é desenvolver conhecimentos e habilidades para:

- Desenvolver interfaces Web modernas;
- Utilizar Frameworks Front-end;
- Trabalhar com Git e GitHub;
- Desenvolver aplicações utilizando diferentes tecnologias;
- Aplicar conceitos de componentização e organização de projetos;
- Publicar aplicações utilizando ferramentas de deploy.

---

## O que é Front-end?

O **Front-end** corresponde à parte de uma aplicação responsável pela interação com o usuário.

É nessa camada que são desenvolvidos elementos como:

- Interfaces;
- Botões;
- Formulários;
- Menus;
- Animações;
- Páginas Web;
- Elementos responsivos.

O desenvolvimento Front-end utiliza tecnologias como **HTML, CSS e JavaScript**, além de frameworks e bibliotecas que facilitam a criação de aplicações mais organizadas e modernas.
